# Модель клуба из CAD-чертежей (Python)

Модель Colibri живёт в `public/models/colibri/` (index.html + club-geom.json + club-plan.jpg); другие клубы — свои папки в `public/models/` и запись в `src/data/clubModels.js`.
Оба файла генерируются из векторных PDF проекта (план ВК «HJ …-Model.pdf» и рабочий проект ОВ, листы 5 и 7).

```
cd tools/plan
python dump.py "<план ВК.pdf>" 1 vk.json            # линии/заливки/тексты страницы -> json
python dump.py "<проект ОВ.pdf>" 5 ov5.json         # отопление
python dump.py "<проект ОВ.pdf>" 7 ov7.json         # вентиляция
python build_geom.py ../../public/models/colibri    # -> club-geom.json + club-plan.jpg
```

`patch_html.py` — одноразовый патч (03.11.2026), которым building-3d.html переведён на эту геометрию;
повторно не запускать.

## Что откуда

| слой | источник | как извлекается |
|---|---|---|
| стены зала, перегородки, колонны | ВК: серые заливки `[0.753]` (тела сэндвич-панелей) | заливка маски → полигоны (cv2.findContours, RETR_CCOMP) |
| кирпичные стены | ВК: X-штриховка (чёрные 0.24, короткие диагонали) | closing 8 px → фигуры ≥ 0.5 м² |
| пристройка, тамбур | ВК: толстые чёрные двойные линии вне зала | closing 7 px |
| воздуховоды | ОВ лист 7: чёрные 1.08 | closing 10 px → полигоны, выдавливаются на 0.45 м под потолком |
| трубы отопления | ОВ лист 5: чёрные 1.08 | полилинии, рисуются линиями на 4.35 м |
| Т3 (ГВС) | ВК: красные заливки-прямоугольники | ось вытянутого полигона (SVD) |
| подложка | ВК: всё, кроме белого; стены перекрашены по маске | 2 см/пиксель, 3575×1330 |

Система координат модели: X вдоль здания (ось 1 = 0, ось 11 = 60), Z поперёк (ось Е = 0, ось А = 22.5), Y вверх.
Масштаб плана ВК: 1 pt = 0.106 м (`X = (x−163.9)·0.106`, `Z = (437.4−y)·0.106`). Листы ОВ привязаны по
габариту зала (0.0351 м/pt, левый угол x=191/137, верх y=741/743 для листов 5/7).

Папка `cryptography/` — заглушка: pdfminer импортирует её только для шифрованных PDF, а настоящая
библиотека (`_rust.pyd`) заблокирована Smart App Control. Запускать скрипты из `tools/plan`, чтобы
заглушка была первой в `sys.path`. Остальные ограничения Python на ноуте — `tools/lidar/README.md`.

## 4YOU (ЖК «4you», 3 уровня) — `build_geom_4you.py`

Источник: рабочий проект ОВ 896-24-ОВ (2025, 15 листов, pdfminer читает текст напрямую). Листы 3/4/5 — отопление −2/1/2 этажей,
6/7/8 — вентиляция, 9/10 — кондиционирование (VRF Gree). Разбор: `python dump.py 100625.pdf N 4you/pN.json` для N=3…10, затем
`python build_geom_4you.py <папка с pN.json> ../../public/models/4you` → `club-geom.json` ({levels:[{id,y0,h,bbox,walls,ducts,heat,cold,fancoils}]})
и подложки `plan-m2.jpg`, `plan-f1.jpg`, `plan-f2.jpg`. Привязка: ось 1 = X 0, ось Д = Z 0; A2-листы x=294/y=995, A3-листы x=193/y=919.9,
масштаб 8400 мм = 238 pt. Стены: серые заливки (1–2 эт.) + серые/чёрные двойные линии (−2) → closing; воздуховоды: красные = приток, синие = вытяжка;
фанкойлы: центры красных кружков символов на листах 9/10 (список FC_M2/FC_F1 в скрипте, модели прочитаны с чертежа). Вьюер `public/models/4you/index.html`
рисует уровни стопкой (−2 = 0, 1 эт. = 7.56, 2 эт. = 12.06, кровля = 16.91) с чипами уровней; оборудование ITEMS/ZONES/SCENARIOS — в самом html.
Альбом дизайн-проекта (122 листа, растр+вектор) использован только для имён помещений.
